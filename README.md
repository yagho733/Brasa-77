# Brasa 77 — Smash & Fire

Site-conceito premium para hamburgueria, com direção visual cinematográfica, cardápio interativo, carrinho e fluxo de pedido.

**Demo oficial:** https://https-github-com-yagho-barbearia-du.vercel.app/

## Principais recursos

- Hero com vídeo, fogo e fumaça
- Fotografias gastronômicas coerentes com o cardápio
- Cardápio interativo por categorias
- Carrinho com quantidade, remoção e total
- Checkout preparado para WhatsApp
- Modo demonstração seguro
- Responsividade para desktop e mobile
- `prefers-reduced-motion` e economia de dados
- Acessibilidade com navegação por teclado e foco visível
- SEO social com Open Graph e Twitter Card
- Configuração do negócio separada em `site-config.js`
- Produtos e preços separados em `menu-data.js`

## Tecnologias

HTML5, CSS3 e JavaScript.

## Personalização

Edite `site-config.js` para endereço, horários, WhatsApp e Instagram. Edite `menu-data.js` para produtos, preços, descrições e fotos.

## Observação

Projeto demonstrativo de portfólio. Dados comerciais e mídias devem ser substituídos pelas informações oficiais do cliente antes de uma publicação real.
